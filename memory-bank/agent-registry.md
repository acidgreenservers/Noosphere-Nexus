## Registry Management

### Agent Onboarding Process
1. **Registration**: Create entry with unique ID and specialization areas
2. **Role Assignment**: Define primary responsibilities and scope
3. **Directory Creation**: Set up `memory-bank/agents/[agent-id]/` personal space
4. **Integration**: Add to shared context and collaboration workflows

### Status Definitions
- **🟢 Active**: Currently engaged in project work
- **🟡 Standby**: Available but not currently assigned
- **🔴 Inactive**: Temporarily unavailable
