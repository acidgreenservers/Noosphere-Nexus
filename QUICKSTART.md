# Quickstart ⚡

This path gets you from **clone → running app** in less than 90 seconds.

## Prerequisites

- **Node.js**: 18+
- **npm**: (included with Node)

## 1) Clone & Enter

```bash
git clone https://github.com/acidgreenservers/Noosphere-Nexus.git
cd Noosphere-Nexus
```

## 2) Install & Run

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

## 3) Access the App

- **Local:** [http://localhost:5173/Noosphere-Nexus/](http://localhost:5173/Noosphere-Nexus/)

## 4) Verify Build

```bash
npm run build
```
