# Quickstart ⚡

This guide outlines the fastest route from **clone** to a **running app**
in under 90 seconds.

## Prerequisites

- **Node.js**: 18+
- **npm**: (included with Node.js)

## 1) Clone & Enter

```bash
git clone https://github.com/acidgreenservers/Noosphere-Nexus.git
cd Noosphere-Nexus
```

## 2) Install & Run

```bash
# Install package dependencies
npm install

# Start local development server
npm run dev
```

## 3) Access the App

- **Local:** [http://localhost:5173/Noosphere-Nexus/](http://localhost:5173/Noosphere-Nexus/)

## 4) Verify Build

```bash
# Build production bundles
npm run build
```
