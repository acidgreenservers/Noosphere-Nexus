## 2025-05-15 - [Tabnabbing and Improper External Link Handling]
**Vulnerability:** External links were opening in new tabs (`target="_blank"`) without `rel="noopener noreferrer"`, exposing the application to tabnabbing. Additionally, the React Router `Link` component was being used for external URLs, which is functionally incorrect and bypasses standard browser security behaviors for external navigation.
**Learning:** React Router's `Link` is specifically for internal client-side routing. Using it for external URLs can lead to broken navigation or unexpected behavior. The absence of `rel="noopener noreferrer"` on `target="_blank"` links is a common but high-priority security gap in React applications that relies on developer vigilance or linting.
**Prevention:** Always use standard `<a>` tags for external URLs. Enforce `rel="noopener noreferrer"` for all `target="_blank"` links via ESLint rules (e.g., `react/jsx-no-target-blank`) to ensure defense-in-depth across the codebase.
